# Game Boy emulator demo

The browser build of a Game Boy (DMG) emulator written in Rust and compiled to
WebAssembly. Play it at https://suhas-svg.github.io/gameboy-emulator-demo/.

This repository holds only the built page. Load your own `.gb` file, or press
"Play demo".
